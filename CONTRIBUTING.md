# Contribuir

1. Haz fork y crea una rama: `git checkout -b docs/nueva-arquitectura`.
2. Para una nueva arquitectura, copia la plantilla de cualquier archivo en `docs/` (Qué es → Para qué sirve → Cómo funciona → Variantes → Pros y contras → Cuándo usarla → Referencias).
3. Usa diagramas **Mermaid** (GitHub los renderiza) y cita papers originales.
4. Si añades código a `examples/`: PyTorch, sin descargas, CPU en pocos segundos, y que termine con un `assert` o `print` verificable.
5. Abre un PR describiendo qué añade o corrige.
